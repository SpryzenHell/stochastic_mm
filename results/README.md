# Research artifacts

These files are generated by:

```bash
python3 scripts/run_research.py --runs 100
```

`research_run.json` is the authoritative raw experiment record for the checked-in run. `python_summary.json` contains derived metrics used by the README. `policy_t0.csv` contains the time-zero inventory policy. The PNG files are generated visualizations and can be recreated from the CSV/JSON outputs.

The results are synthetic and machine-dependent.
